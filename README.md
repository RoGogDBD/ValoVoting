## Обзор

ValoVoting подключается к Twitch через EventSub WebSocket и в реальном времени транслирует результаты опроса на оверлей в OBS. Карты сортируются по голосам с плавной анимацией, artwork подгружается с `valorant-api.com`, по окончании опроса появляется плашка победителя.

Голосование запускается командой в чате — доступно только стримеру и модераторам. Никакой регистрации приложения Twitch не нужно: достаточно войти в свой аккаунт при первом запуске.

> [!NOTE]
> Создание нативных опросов через Twitch API доступно только партнёрам и аффилиатам. Если у тебя обычный канал — опрос нужно создать вручную в Twitch Dashboard; оверлей подхватит его автоматически через EventSub.

## Быстрый старт

Скачай актуальную версию `valovoting.exe` со [страницы релизов](https://github.com/kudryavtsevmakar/valovoting/releases) и запусти её двойным кликом.

При первом запуске откроется мастер настройки:

1. Браузер автоматически откроется на странице авторизации Twitch — войди в аккаунт стримера
2. После входа страница закроется, терминал продолжит настройку
3. Укажи команду в чате, длительность опроса и порт (или оставь значения по умолчанию)
4. Настройки сохранятся в `.env` рядом с `.exe` — при следующем запуске мастер больше не появится

```
  ╔═══════════════════════════════════════════════════════╗
  ║  ▸ VALORANT POLL OVERLAY                             ║
  ╚═══════════════════════════════════════════════════════╝

  [ 1 / 3 ]  Вход в Twitch
  ────────────────────────────────────────────────────────
  Открываем браузер. После входа страница закроется автоматически.

  [ 2 / 3 ]  Настройки бота
  ────────────────────────────────────────────────────────
  Команда в чате [!mapvote]
  Длительность опроса (сек) [60]
  HTTP-порт [8080]

  [ 3 / 3 ]  Сохранение
  ────────────────────────────────────────────────────────
  ✓  .env сохранён
```

> [!TIP]
> Чтобы сменить аккаунт или переписать настройки — удали `.env` рядом с `.exe` и перезапусти программу.

## OBS

1. **Sources → Add → Browser Source**
2. URL: `http://localhost:8080/overlay`
3. Width: `1920`, Height: `1080`
4. Custom CSS:
   ```css
   body { background: transparent !important; }
   ```

Оверлей позиционируется в правом нижнем углу с прозрачным фоном и автоматически скрывается через 30 секунд после завершения опроса.

## Команда в чате

Команду может написать только **стример или модератор** — остальные сообщения игнорируются.

**Синтаксис:**

```
!mapvote [-карта1] [-карта2] [длительность]
```

| Пример | Результат |
|---|---|
| `!mapvote` | Все карты из пула (до 5 случайных — лимит Twitch) |
| `!mapvote 90` | То же, но опрос идёт 90 секунд |
| `!mapvote -bind -icebox` | Убрать Bind и Icebox |
| `!mapvote -bind,icebox 120` | То же через запятую, 120 секунд |

Исключение карт работает по префиксу без учёта регистра: `-as` уберёт Ascent, `-ic` — Icebox.

**Текущий пул карт:**

```
Abyss · Ascent · Bind · Haven · Icebox · Lotus · Pearl · Split · Sunset
```

Список обновляется вручную в `internal/twitch/maps.go` при изменении соревновательного пула.

## Как это работает

```text
+-------------------+     команда в чате     +-------------------+
| Стример/модератор | ---------------------> | Chat Bot (IRC)    |
+-------------------+                        +-------------------+
                                                       |
                                              создание опроса
                                                       |
                                                       v
+-------------------+     EventSub WS        +-------------------+
| Twitch Polls      | ---------------------> | Go Backend        |
| begin/progress/   |                        | poll.Service      |
| end               |                        | hub.Broadcast     |
+-------------------+                        +-------------------+
                                                       |
                                               WS push update
                                                       |
                                                       v
                                             +-------------------+
                                             | OBS Overlay       |
                                             | browser source    |
                                             | :8080/overlay     |
                                             +-------------------+
```

Сервер подписывается на три события Twitch EventSub:

- `channel.poll.begin` — опрос начался, оверлей появляется
- `channel.poll.progress` — обновление голосов, карты сортируются в реальном времени
- `channel.poll.end` — опрос завершён, показывается плашка победителя

При разрыве соединения EventSub и IRC автоматически переподключаются с экспоненциальным backoff (1 с → 2 с → … → 30 с).

**Оверлей:**

- Artwork карт подгружается с `valorant-api.com` при загрузке страницы
- Карта с наибольшим числом голосов поднимается наверх с плавной анимацией
- При разрыве WebSocket-соединения браузер автоматически переподключается
- Плашка победителя скрывается через 30 секунд

**Определение фазы** — бейдж меняется автоматически по ключевым словам в названии опроса:

| Слово в названии | Бейдж |
|---|---|
| `карт`, `map` | `MAP VOTE` |
| `агент`, `agent` | `AGENT VOTE` |
| Всё остальное | `MAP VOTE` |

## Настройки (.env)

Файл создаётся мастером автоматически. При необходимости можно отредактировать вручную:

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `TWITCH_BROADCASTER_ID` | ✓ | — | Числовой ID канала |
| `TWITCH_ACCESS_TOKEN` | ✓ | — | OAuth-токен (выдаётся мастером) |
| `TWITCH_CHANNEL` | ✓ | — | Логин стримера (например `rogog_`) |
| `CHAT_COMMAND` | — | `!mapvote` | Команда запуска голосования |
| `DEFAULT_POLL_DURATION` | — | `60` | Длительность опроса в секундах (15–1800) |
| `PORT` | — | `8080` | HTTP-порт оверлея |

## Сборка из исходников

**Требования:** Go 1.22+

```bash
# Запуск из исходников
make run

# Сборка бинаря под текущую ОС
make build

# Кросс-компиляция Windows .exe (с Linux / macOS)
make release
```

Версия и Client ID встраиваются в бинарь через `-ldflags`:

```bash
go build \
  -ldflags="-X main.version=v1.0.0 -X github.com/kudryavtsevmakar/valovoting/internal/config.TwitchClientID=YOUR_ID" \
  -o valovoting ./cmd/server
```
